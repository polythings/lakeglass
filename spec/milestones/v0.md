# v0: explore a bucket in the browser

**Planned** · updated 2026-10-19

## Summary

The first usable version proves the whole path from a bucket to a byte on the most common formats: plain Parquet files and Iceberg and Delta Lake tables, in the browser with nothing to install. File anatomy and the table explorer cover Parquet, Arrow IPC, Avro, Iceberg, Delta, and Hive-style directories; the other formats come in later milestones behind the same interfaces.
