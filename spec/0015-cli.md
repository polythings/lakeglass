# 15. CLI and local server

**Planned** · updated 2026-10-19 · milestones: [v0](milestones/v0.md) (script commands),
[Desktop](milestones/desktop.md) (`open`)
· related: [spec 13](0013-browser-app.md), [spec 14](0014-mac-app.md), [spec 18](0018-packages.md)

## Summary

`lakeglass` is a command-line tool for Linux, macOS, and Windows. `lakeglass open <url>` serves the interface on
localhost with the native core, for machines without the Mac app and for buckets without CORS. Other commands print
what the interface shows: a store map, a file's anatomy, a table's snapshots, checks, and SQL results.

## Design

- `lakeglass open [url]`: serve the embedded static interface and the HTTP backend on 127.0.0.1 with a per-launch
  token ([security](security.md)), and open the browser.
- `lakeglass map <url>`, `lakeglass file <url>`, `lakeglass table <url>`, `lakeglass check <url>`,
  `lakeglass sql <url> "<query>"`: text or JSON output (`--json`), for scripts and CI.
- The binary embeds the interface's static files, so one download runs everything.
- The Python package (spec 18) wraps the same core for notebooks: `lakeglass.open(url)`, `lakeglass.anatomy(url)`
  returning Python objects and Arrow tables.
